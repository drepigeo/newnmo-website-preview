# National Medicos Organisation (NMO) — Official Website

Official website for the **National Medicos Organisation (NMO)** (*स्वास्थ्य सेवा, राष्ट्र सेवा* — *Swasthya Sewa, Rashtra Sewa*), an all-India fraternity uniting qualified allopathic doctors, dental surgeons, medical educators, and students in service of rural, tribal, and border frontiers of Bharat since 1977.

## 3. Gallery Layout & Responsive Behavior

* **Desktop Layout:** 4 cards per row, 170px thumbnail height, neat 12px gap.
* **Tablet Layout:** 3 cards per row, 160px thumbnail height, 10px gap.
* **Mobile Layout:** 2 cards per row, 135px thumbnail height, 8px gap.
* **Aspect Ratio & Fit:** `object-fit: cover` ensures all thumbnails remain visually consistent without distortion.
* **Interactive Lightbox:** Clicking any image opens a fullscreen lightbox showing the uncropped high-resolution photograph (`object-fit: contain`) with Prev/Next navigation, live image counter, and keyboard shortcuts (<kbd>Esc</kbd>, <kbd>←</kbd>, <kbd>→</kbd>).
* **Infallible Local & Offline Fallback:** Every image contains an automated fallback cascade (checking `assets/images/nmocon-2026/`, `nmocon-2026/`, root folder, and embedded Base64 thumbnail data URI). Images will never break even if the file is opened offline or without extracting subfolders.

## 4. Local Viewing Instructions

1. **Extract the ZIP Archive:**
   Extract `nmo_website.zip` to any local folder on your computer.
2. **Open in Browser:**
   Double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.
3. **Navigate the Gallery:**
   Scroll down to the **Events & National Assemblies** section or click **Events & NMOCON** in the top navigation bar to access the compact gallery and filter by categories.

## 5. GitHub Pages Deployment Steps

1. **Initialize Git Repository:**
   ```bash
   git init
   git add .
   git commit -m "Update NMO website: NMOCON 2026 compact gallery with all 20 authentic photos"
   ```
2. **Push to GitHub Repository:**
   ```bash
   git branch -M main
   git remote add origin https://github.com/<your-username>/<your-repo-name>.git
   git push -u origin main
   ```
3. **Enable GitHub Pages:**
   * Open repository **Settings** on GitHub.
   * Under **Pages**, select **Deploy from a branch**.
   * Choose branch `main` and folder `/ (root)`.
   * Click **Save**.
4. **Live Access:**
   Your website will be live within 1–2 minutes at `https://<your-username>.github.io/<your-repo-name>/`.
